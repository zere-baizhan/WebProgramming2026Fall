Remote Patient Monitoring

Continuous insight into metabolic syndrome, in real time.

This project is designed for educational purpose in KBTU 2026 by Zere Baizhan. This project is about IoT sensors that track the five core indicators of metabolic syndrome: temperature, glucose, heart rate, blood pressure and cardiac rhythm and then streams them to a single dashboard for doctors.
